# Sahayak

Sahayak is a modular, stateless MCP server that delivers voice-assistant capabilities through Alexa+ add-ons. Academics is the first launch module.

## Development

Install the pinned Python 3.12 toolchain and development dependencies:

```sh
make setup
make lint
make test
```

The repository is intentionally scaffolded in T0.1. Application, container, and MCP-server functionality arrive in their dedicated tasks.

Product planning and engineering working notes are maintained locally; this repository intentionally tracks only this README as Markdown.
